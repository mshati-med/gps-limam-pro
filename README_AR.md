# GPS LIMAM — بداية مشروع Flutter

هذه نسخة أولية قابلة للبناء، وليست التطبيق النهائي. تحتوي على:
- واجهة عربية RTL بتصميم Material 3.
- خريطة تجريبية عبر الإنترنت مع إظهار موقع GPS بعد منح الإذن.
- تبديل الوضع الداكن/الفاتح وحفظ الاختيار محليًا.
- أقسام أولية للأصدقاء والدردشة والخرائط المحفوظة والإعدادات.
- سير عمل GitHub Actions لبناء APK وإرفاقه كـ Artifact.

## تنبيه حول الخرائط
الخريطة الحالية تجريبية ومتّصلة بالإنترنت. لم تُنفّذ بعد ميزة تنزيل دولة كاملة. لا تستخدم التنزيل الجماعي من خادم البلاطات العام `tile.openstreetmap.org`؛ يجب اختيار مزود خرائط يسمح بالتنزيل المسبق أو تجهيز أرشيف MBTiles من مصدر مرخّص، مع الالتزام بنسبة المصدر وشروط الاستخدام. بيانات الطرق ومحرك التوجيه دون اتصال مرحلة منفصلة.

## كيف تبني APK من الهاتف
1. أنشئ مستودع GitHub جديدًا باسم `gps-limam`، واجعله خاصًا إن رغبت.
2. ارفع محتويات هذا المشروع إلى جذر المستودع، وليس ملف ZIP وحده.
3. افتح تبويب **Actions** وفعّل Actions إذا طلب GitHub ذلك.
4. اختر **Build GPS LIMAM APK** ثم **Run workflow**.
5. انتظر حتى ينتهي التشغيل بنجاح، وافتح التشغيل المكتمل.
6. في قسم **Artifacts** نزّل `gps-limam-android-apk` ثم فك ضغطه لتحصل على `app-release.apk`.
7. افتح APK على هاتف أندرويد وثبّته بعد السماح بالتثبيت من المصدر الذي نزّلت منه الملف.

يمكن تشغيل البناء تلقائيًا عند كل push إلى الفرع `main`.

## إعداد أندرويد
الأرشيف يحتوي على ملفات المصدر الأساسية وليس هيكل Android كاملًا. سير العمل في GitHub Actions ينشئ ملفات منصة Android تلقائيًا، ثم يضيف أذونات الإنترنت والموقع قبل البناء.

## مراحل العمل التالية
1. إنشاء مشروع Flutter كامل ثم دمج `lib/main.dart` و`pubspec.yaml`.
2. اختبار الخريطة وGPS على جهاز حقيقي.
3. اختيار مصدر خرائط مرخّص وتنفيذ تنزيل مناطق محددة وتخزينها محليًا (MBTiles/PMTiles أو حل مناسب).
4. تنفيذ حسابات المستخدمين وطلبات الصداقة وقواعد الصلاحيات في backend.
5. تنفيذ مشاركة الموقع اللحظية مع موافقة صريحة وحدود تحديث للحفاظ على البطارية.
6. تنفيذ دردشة فورية وإشعارات واختبارات أمان.
7. توقيع إصدار الإنتاج بمفتاح خاص محفوظ كـ GitHub Secret، لا داخل المستودع.

## التكلفة
ملفات المشروع وGitHub Actions ضمن حدود الاستخدام المجاني المتاحة للحساب، لكن الحدود قد تتغير. أي خدمة خرائط أو استضافة أو استخدام يتجاوز الحصة المجانية قد يفرض تكلفة؛ لا تفعّل خطة مدفوعة أو تضف وسيلة دفع قبل مراجعة التكلفة.
